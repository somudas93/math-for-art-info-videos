# Mathematical Art Laboratory

Mathematics can act as a visual grammar.

A useful abstraction:

**artwork = structure + mathematics + controlled randomness + composition**

The laboratory will explore:

- parametric geometry
- polar coordinates
- deterministic randomness
- noise
- flow fields
- branching and L-systems
- particles
- recursive geometry
- fractals

Financial mappings will include:

| Financial idea | Visual language |
|---|---|
| Compound growth | exponential / recursive growth |
| Inflation | inverse growth / shrinking purchasing power |
| SIP | repeated particle injection + compounding |
| Loan amortization | recurrence + changing proportions |
| Risk | dispersion / distributions |
| Diversification | correlated trajectories / networks |
| Liquidity | flow fields / density |
| Market uncertainty | stochastic trajectories |

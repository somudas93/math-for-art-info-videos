# Procedural Art Experiments

Experiments are numbered in the order we expect to study them.

01 Geometry
- parametric curves
- polar coordinates
- radial repetition

02 Noise
- seeded randomness
- smooth fields
- multi-scale structure

03 Flow Fields
- vector fields
- numerical integration
- trajectories

04 Fractals
- recursive geometry
- self-similarity

05 L-Systems
- symbolic rewriting
- branching structures

06 Particles
- particle state
- trajectories
- flow-based motion

The goal is to discover reusable visual primitives before coupling them to finance or video rendering.
